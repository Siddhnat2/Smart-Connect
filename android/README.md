# RemoteSupport for Android

Native Android app (Kotlin, no UI libraries) that connects to the **RemoteSupport desktop app**
and lets you see and control that computer from your phone. It speaks the exact same protocol
(mutual password proof + AES-256-GCM end-to-end encryption), so the PC side needs no changes.

## Get the APK from GitHub (no Android Studio needed)
1. Push this whole repository to GitHub (branch `main`).
2. Open the **Actions** tab -> **Build Android APK** (it starts by itself on push; or press *Run workflow*).
3. When it is green, open the run and download the artifact **RemoteSupport-Android-APK** -> `RemoteSupport.apk`.
4. Copy it to the phone and open it (allow *Install unknown apps* once). Publishing a GitHub **Release**
   attaches `RemoteSupport.apk` to the release automatically.

### Optional: sign with your own key (recommended if you will update the app later)
Updates only install over an older version when both are signed with the same key. Create a key once:
```bash
keytool -genkeypair -v -keystore release.jks -alias remotesupport -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks      # macOS: base64 -i release.jks
```
Add four repository secrets (Settings -> Secrets and variables -> Actions):
`ANDROID_KEYSTORE_BASE64` (the base64 text), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
Keep `release.jks` private and backed up; never commit it.

## Using it
1. On the computer: open RemoteSupport (sharing is on). Note **Address**, **ID**, **Password**.
2. On the phone: enter them and tap **Connect**. The person at the computer taps **Allow**.
3. Reach the PC over the same Wi-Fi, or anywhere with **Tailscale** installed on both (use the PC's `100.x.x.x`).

| Gesture | Action |
|---|---|
| Tap | Left click (tap twice quickly = double click) |
| Long press | Right click |
| Move one finger | Move the pointer |
| **Drag: ON** (toolbar), then move a finger | Hold the left button: move windows, select text |
| Two fingers up/down/sideways | Scroll |
| Pinch, then drag with two fingers | Zoom / pan (**Fit** resets) |
| **Keyboard** button | Soft keyboard + bar with Esc, Tab, Ctrl/Alt/Shift/Win (tap to arm for the next key), arrows, Home/End, PgUp/PgDn, Del, F5, F11 |

Hardware keyboards work too.

## Build locally
Open the `android/` folder in Android Studio (Hedgehog or newer) and press Run, or with JDK 17 and Gradle 8.7:
```bash
cd android && gradle assembleRelease      # -> app/build/outputs/apk/release/app-release.apk
gradle testDebugUnitTest                  # crypto test vectors generated by the desktop app's own code
```

## What this app is not
* It controls **computers**. Controlling an Android phone *from* the PC is not possible with this app
  (Android only allows that to special, user-granted accessibility services); sharing the phone's screen
  view-only would need a separate "host" mode and a matching viewer in the desktop app.
* The cleartext `ws://` transport is allowed on purpose: the app encrypts and authenticates everything itself.
  Use only on computers whose owner has agreed to the session.
